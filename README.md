# ETLPipeline

The **ETLPipeline** project is a hands-on learning project designed to explore the end-to-end **ETL (Extract, Transform, Load)** process and strengthen core **data engineering skills**. This was created using sample, unsanitized data with the end goal of being loaded into an Microsoft SQL based data warehouse environment. 

## Features

- **Data Extraction**: Collect data from multiple sources such as CSV files, APIs, and databases.
- **Data Transformation**: Clean, validate, and enrich data using Python and libraries like Pandas to prepare it for analysis.
- **Data Loading**: Store processed data into target destinations like relational databases or data warehouses, with proper schema management.

## Learning Goals

- Understand the full ETL process from raw data to structured storage.
- Apply best practices in **data pipeline design**, **automation**, and **data quality**.
- Gain practical experience preparing datasets for analytics or downstream applications.

This project is ideal for anyone looking to build practical ETL experience and enhance their data engineering portfolio.
